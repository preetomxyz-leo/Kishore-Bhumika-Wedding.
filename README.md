# শ্রীমান কিশোর সাহা & শ্রীমতি ভূমিকা সাহা — বিবাহ আমন্ত্রণ

একটি প্রিমিয়াম, মোবাইল-ফ্রেন্ডলি বাঙালি হিন্দু বিবাহ আমন্ত্রণ ওয়েবসাইট।

## ফাইল কাঠামো

- `index.html` — মূল ওয়েবসাইট পৃষ্ঠা
- `style.css` — সমস্ত স্টাইলিং
- `script.js` — কনফিগারেশন, কাউন্টডাউন এবং ইন্টারঅ্যাকশন
- `images/placeholder.svg` — ছবি নেই তখন ডিফল্ট প্লেসহোল্ডার
- `favicon.svg` — সাইট আইকন
- `README.md` — এই ফাইল

## কীভাবে ব্যবহার করবেন

১. `index.html` ফাইলটি যেকোনো ব্রাউজারে খুলুন।
২. ছবি যোগ করতে `images/` ফোল্ডারে এই ফাইলগুলো রাখুন:
   - `groom.webp` — বরের ছবি
   - `bride.webp` — কন্যার ছবি
   - `couple.webp` — দম্পতির ছবি
৩. বিবাহের তারিখ, স্থান এবং অন্যান্য বিবরণ পরিবর্তন করতে `script.js` ফাইলের উপরে থাকা `WEDDING_CONFIG` ব্লকটি সম্পাদনা করুন।

## হোস্টিং

এটি একটি সম্পূর্ণ স্ট্যাটিক ওয়েবসাইট। গITHUB পেজ বা ভার্সেলে সরাসরি আপলোড করুন। কোন বিল্ড প্রসেস বা নোড জেএস প্রয়োজন নেই।
